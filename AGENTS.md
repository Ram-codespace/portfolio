# Portfolio

Personal portfolio built with Next.js 16 (App Router, React 19, TypeScript), Tailwind CSS v4 and GSAP.

## Commands
- `npm run dev` — Start dev server
- `npm run build` — Production build
- `npm run lint` — ESLint check
- `npm run typecheck` — TypeScript check
- `npm run check` — Run lint + typecheck + build

## Structure
- `src/app/` — routes and global styles
- `src/components/sites/portfolio/` — page sections
- `public/portfolio/` — images and videos
